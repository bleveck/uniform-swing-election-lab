# Shared laptop election snapshots

Only public watchlist vote totals, source clocks, test flags, and provider status are published here.
`latest.json` is replaced cumulatively; failures retain each provider's last successful totals.
Preparation/test data are excluded by the app. The snapshot can become stale when the laptop stops.
App source and instructions: https://github.com/bleveck/uniform-swing-election-lab
